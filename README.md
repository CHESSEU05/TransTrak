# TransTrak

**TransTrak** is a mobile application prototype for local transport tracking of taxis and motorcycles in Cameroon. The system is designed to improve transport visibility, passenger-driver coordination, route-aware driver matching, real-time tracking, reporting, and basic administrative supervision.

This project is developed as part of a final year software engineering project.

---

## Project Overview

In many local transport environments, passengers often depend on roadside waiting, random encounters, or informal knowledge to find taxis and motorcycles. This creates uncertainty, delays, and weak coordination between passengers and transport operators.

TransTrak addresses this problem by allowing drivers to become visible through location sharing, availability updates, and intended route entry. Passengers can search for nearby or route-matched drivers, send transport requests, and track accepted drivers in real time.

The system is not intended to be a full commercial ride-hailing platform. It is a lightweight academic prototype focused on local transport visibility and coordination.

## Main Features

### Passenger Features

- User registration and login
- Passenger profile management
- Pickup and destination entry
- Nearby driver search
- Route-aware driver matching
- Driver details viewing
- Transport request submission
- Request status tracking
- Real-time driver tracking
- Report submission
- In-app notifications

### Driver Features

- Driver registration and login
- Driver profile management
- Vehicle information management
- Driver verification status
- Availability management
- GPS location sharing
- Intended route entry
- Incoming request handling
- Accept or reject passenger requests
- Real-time tracking updates
- Report submission

### Administrator Features

- Admin dashboard
- User management
- Driver verification
- Report management
- Basic system activity monitoring
